# Contribuire ai progetti LU3G

1. Crea un branch `fix/`, `feature/` o `chore/` da una base aggiornata.
2. Mantieni la modifica limitata a un obiettivo verificabile.
3. Non inserire credenziali, dati personali, database, upload, log o backup.
4. Esegui i test del progetto e documenta il risultato nella pull request.
5. Descrivi impatto, migrazioni, deploy, readback e rollback.

Nessun test deve generare lead, email, webhook, pubblicazioni o altri effetti
reali senza un'autorizzazione esplicita e un ambiente controllato.
